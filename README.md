# Atmosphere Autopilot Redux

***License: GPL-3***

A very simple port of the awesome KSP1 atmosphere autopilot mod to KSP2 Redux.

To use it enable the feature in a new or already existing campaign and press the button on the app-bar.

Note: A lot of this port was done via the aid of LLM, though I have done testing to confirm everything ported works as intended.

Original Mod: https://github.com/Boris-Barboris/AtmosphereAutopilot
